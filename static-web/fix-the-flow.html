Sprint 5: Fix the Flow

Topics

  • 01/12/2025
  • micro interaction
  • state
  • navigation
  • wireflow
  • user story
  • js
  • user testing

In de sprint Fix the flow leer je over navigatie systemen, hoe je informatie op een goede manier kunt presenteren en een gebruiker feedback kan geven.

De focus van deze sprint ligt op interactie en informatie architectuur van een website.

Criteria

    • 1.3 Benoemt belangen van eindgebruikers, valideert door middel van testen en verwerkt testresultaten.
    • 3.2 Kan binnen de squad ontwerpkeuzes, eigen ideeën en producten begrijpelijk verwoorden
    • 4.1 Analyseert een vraag en volgt de aangeboden oplossingsrichting.
    • 4.2 Schetst om gedachten en processen te verkennen.
    • 4.3 Bedenkt en implementeert eenvoudige frontend code en gebruikt daarbij de fundamentele principes van het web.
    • 5.2 Maakt aangeboden en zelf gevonden materie eigen en gebruikt dit bij leertaken.
